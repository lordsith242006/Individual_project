# Сервис планирования консультационных часов

## Назначение
Приложение для записи студентов на консультации к преподавателям.

## Целевая аудитория
Студенты и преподаватели.

## Предметная область
Организация консультаций: выбор преподавателя, времени и создание записи.

## Основные сущности
- Преподаватель
- Консультация
- Время
- Запись

## Основные функции
- Показать список преподавателей
- Показать доступное время консультации
- Записать студента на консультацию

## План развития
- веб-приложение на Django
- база данных
- пользователи и авторизация
- REST API
- Docker
- CI/CD
