# Сервис планирования консультационных часов

Консольное приложение для записи студентов на консультации к преподавателям.

## Целевая аудитория
Студенты и преподаватели.

## Предметная область
Организация консультаций: выбор преподавателя, проверка свободных мест
на выбранную дату, создание и отмена записи.

## Возможности
- просмотр, поиск, отбор и сортировка преподавателей;
- добавление преподавателя;
- проверка количества мест на консультации;
- проверка наличия свободных мест на дату;
- запись студента на консультацию (запрет повторной записи и переполнения);
- отмена записи;
- просмотр всех записей.

## Структура проекта
```
Individual_project/
├── README.md
├── requirements.txt
├── main.py             — точка запуска, меню, вывод списков
├── teachers.py         — функции работы с преподавателями
├── appointments.py     — функции записи на консультации
├── storage.py          — сохранение и загрузка JSON
├── utils.py            — безопасный ввод чисел, дат и строк
├── data/
│   ├── teachers.json
│   └── appointments.json
└── tests/              — автоматизированные тесты pytest
```

## Формат данных
`data/teachers.json` — список преподавателей:
```json
{"id": 1, "name": "Иванов И.И.", "department": "Информатика",
 "max_students": 3, "consultation_time": "14:00"}
```
`data/appointments.json` — список записей:
```json
{"id": 1, "teacher_id": 1, "student_name": "Смирнов Алексей",
 "consultation_date": "2026-09-20"}
```
В программе преподаватели хранятся в словаре `{id: данные}`,
записи — в списке словарей.
